# Природні мандри

## Про проєкт

**Природні мандри** — вебзастосунок, присвячений подорожам, природним локаціям та цікавим місцям. Він допомагає користувачам знаходити ідеї для подорожей, переглядати історії інших мандрівників, зберігати цікаві публікації та ділитися власним досвідом.

Мета проєкту — об’єднати корисну інформацію про подорожі в одному місці та зробити планування мандрівок зручнішим.

## Основні можливості

- Перегляд історій про подорожі.
- Фільтрація історій за категоріями.
- Перегляд детальної інформації про окрему історію.
- Реєстрація та авторизація користувачів.
- Створення власних історій.
- Додавання історій до збережених.
- Перегляд власних публікацій і збережених історій.
- Пагінація списків історій.

_Перелік можливостей може уточнюватися в процесі розробки._

## Технології

- **Node.js** — серверне середовище виконання JavaScript.
- **Express.js** — створення серверної частини та REST API.
- **MongoDB Atlas** — хмарна база даних.
- **Mongoose** — робота з MongoDB через моделі та схеми.
- **Git та GitHub** — контроль версій і спільна розробка.
- **CORS** — налаштування доступу до API з інших джерел.
- **dotenv** — завантаження змінних середовища.

## Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone <repository-url>
cd tandem
```

### 2. Встановлення залежностей

```bash
npm install
```

### 3. Налаштування змінних середовища

Створіть файл `.env` у корені проєкту та додайте необхідні змінні:

```env
PORT=3000
MONGODB_URI=<your-mongodb-connection-string>
```

Замість `<your-mongodb-connection-string>` вкажіть рядок підключення до MongoDB Atlas.

Не додавайте файл `.env` до репозиторію та не публікуйте облікові дані бази даних.

### 4. Запуск у режимі розробки

```bash
npm run dev
```

Команда запуску залежить від налаштувань у `package.json`.

## База даних

Проєкт використовує MongoDB Atlas.

Основні колекції:

- `users` — дані користувачів.
- `stories` — історії та публікації про подорожі.
- `categories` — категорії історій.

Для підключення до бази даних використовується змінна середовища `MONGODB_URI`.

## Командна розробка

Проєкт розробляється командою з використанням Git та GitHub.

Перед внесенням змін рекомендується отримати останню версію коду:

```bash
git pull
```

Для роботи над окремими завданнями використовуйте окремі гілки та створюйте Pull Request перед об’єднанням змін.
